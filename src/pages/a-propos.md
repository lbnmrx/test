# À propos

Cette page est écrite en **Markdown**, comme le README du dépôt : un simple texte, sans aucune balise HTML.

Astro la transforme en page web et l'habille avec le même gabarit que les autres, en-tête compris.

## Ce que ce dépôt m'a appris

- un **commit** enregistre une modification avec un message ;
- une **branche** permet de travailler à part, sans toucher à `main` ;
- une **pull request** soumet le travail à la relecture avant fusion ;
- **Cloudflare** republie le site à chaque fusion, après la fabrication par **Astro**.
